# 社会调研与社科论文写作方法

给实证社科研究用的 Codex Skill。你可以把一个宽泛的选题交给它，得到能实施的方案。也可以带着一份问卷、访谈逐字稿或论文初稿，让它直接完成当前环节。

## 可以做什么

| 当你遇到 | 适用环节 | 可以交付 |
|---|---|---|
| 题目太大，或不知道现有资料能回答什么 | 选题、文献综述、开题 | 主研究问题、文献矩阵、可行性判断、调研方案与论文提纲 |
| 问卷不好答、样本不知道怎么选、访谈问不出实际经历 | 调研设计、取样、前测及现场收集 | 抽样方案、问卷与计分规则、前测记录、访谈提纲和日志 |
| 有访谈、档案、帖子或影像，缺少一致的分析办法 | 质性分析、个案分析、内容分析 | 编码簿、案例证据表、含分母的结果表 |
| 论文结论太强，或研究报告难以快速核对 | 写作、审稿、成果传播 | 论断与证据对照、改写段落、报告和数码叙事分镜 |

每张方法卡都写明启动所需的材料、操作步骤、分支、交付物和完成标准。可以先看[完整方法导航](SKILL.md)，也可以直接打开[实操案例](references/worked-example.md)和[可填写工作表](resources/work-sheets.md)。

## 安装与调用

将仓库放到 Codex 的个人 Skills 目录。确保 `social-research-writing` 文件夹下直接包含 `SKILL.md`。初次安装可执行以下命令。

```bash
git clone https://github.com/Valentina-Qiao/social-research-writing.git ~/.codex/skills/social-research-writing
```

下一轮对话可以这样调用。

> 用 `$social-research-writing` 帮我做一份可执行的夜校调研方案。我只有四周，有报名表但还没确认能不能拿到签到。请先判断哪些问题能回答，再给我取证步骤和访谈提纲。

方法蒸馏自十讲社会调研课件和一份数码叙事专题。[课件页码及适用范围](references/overview.md)可用于核对来源。
