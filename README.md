# 社会调研与社科论文写作方法

一个面向实证社科研究的 Codex Skill。可以从选题一路做到调研方案和论文，也可以只调用一个环节，例如抽样设计、访谈编码或结论审查。

## 安装与调用

将此仓库复制或克隆到 Codex 的个人 Skills 目录下。默认安装目录为 `~/.codex/skills/social-research-writing/`，其中应直接包含 `SKILL.md`。

```bash
git clone https://github.com/Valentina-Qiao/social-research-writing.git ~/.codex/skills/social-research-writing
```

在 Codex 下一轮对话中可以这样调用。

> 用 `$social-research-writing` 帮我把这个选题收窄成一个可回答的问题，并设计四周内能完成的调研方案。

也可以提供材料，直接要求生成问卷和前测表、对访谈逐字稿做初步编码，或逐条检查论文结论与证据是否对应。

## 方法覆盖

- **研究设计** · 选题与研究问题、文献综述、研究设计、抽样。
- **调研实施** · 个案研究、调研策划与答辩、问卷、访谈与质性编码、内容分析。
- **写作与传播** · 实证社科论文、调研报告与质量评估、数码叙事。

Skill 蒸馏自十讲社会调研课件和一份数码叙事专题。能力卡标明原课件页码，工作表可以按项目直接填写。
