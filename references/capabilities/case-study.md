# 个案研究

## 使用场景

收集和分析组织、社区、项目或事件资料时使用。适合还原过程、比较案例、解释异常或检验理论的适用条件。

## 最小输入

研究问题、候选个案、场域时间边界、可收集的访谈、观察或档案。比较时还需说明两案能共享的观察口径。

## 决策规则

- 深描特殊过程或追踪机制可聚焦一案。比较异同时先定共同问题、边界和比较轴，再分别完成每案时间线。
- 文档和访谈若都源于同一通告，标为同源。两个案子的资料生成方式不同，先核对哪类事件更容易留下记录。
- 解释冲突时保留各来源原貌与日期，列出能区分候选解释的待补证据。

## 操作步骤

1. 收集主问题、候选案例、比较对象和可访问资料。如从熟悉场域开始，从未发生的预期变化或反常变化找研究问题。如从理论开始，写出理论预期与可观测迹象后再找案例。交付案例卡，包含案例、研究对象、地点、起止时间、入界与排除条件、主分析单位及嵌套次单元。边界不清时，先提炼成可观察的一段过程或补齐范围。
2. 定选案逻辑。一案适合细描过程或专查其特殊性。多案需要共同问题、口径和可比较字段；可按角色、单位、时段嵌套观察，并写出次单元如何帮助理解主单元。说明所用选案逻辑及其依据。

   | 目的 | 选案及核验 |
   |---|---|
   | 查看理论预期过程 | 选理论能够解释的典型案例，列出预期机制及证实或抵触它的线索 |
   | 比较差异 | 至少两个共享比较轴的案例，记录关键变量差异及其他条件 |
   | 利用极端值生成启示 | 明确极端指标、参照分布或对比组及极端性何以重要 |
   | 解释偏离理论预期 | 给出理论预测、案内观察和偏离所在，检查新解释 |
   | 检查重大事件对理论假定的挑战 | 交代事件为何影响既有解释，核验被忽略的变量或条件 |

3. 确定分析方向。由果追因，把结果拆成可核验现象，再区分背景条件、近因与中间过程。由因推果，界定事件和起点，区分直接变化与同其他事件合并出现的间接变化。列时间线并逐项注明时间、行动者、行动、结果、资料位置、事实状态。
4. 建立证据表。对每个论点列出预期可见迹象、访谈/观察/档案依据、位置、来源是否独立、矛盾与替代解释。取得材料时同步保留时地、出处、范围和使用权限。再核对时间顺序，以及何种证据可区分其他解释。证据冲突时保留冲突及补采计划。多案先完成各案同口径分析，再按比较轴汇总共性、分歧和适用条件。
5. 交付案例卡、选案理由、时间线、证据表和正文提纲。前因型写背景、事件过程和分析。后果型写事件过程、直接/间接影响和分析。实践型若需提出方案，再逐项比较方案的可行条件、预计效果与局限。验收时检查中心论断能否回到边界内的证据，以及分析给出的每条建议是否对应所诊断的问题。

## 交付物与验收

交付案例边界和选案说明、时间线、证据矩阵。多案另交共同口径下的各案发现、差异及适用情境。

- 关键事件与结论可定位到案内记录。没有确认的事件用待核状态保留。
- 解释能经受时间顺序和至少一个有根据的替代解释检查。比例推断另有合适的抽样依据。

**交接。** 将定位后的证据矩阵交给论文写作卡，按过程、解释及限制组织章节。

可复制[对应工作表](../../resources/work-sheets.md#抽样与个案)。跨阶段项目沿用[研究证据与交接表](../../resources/work-sheets.md#研究证据与交接表)的问题编号。

## 实例

课件演示，第 5 讲第 46–47 页。以机关工作人员外出后空调仍开启为事件切口，关注开关控制方式、能源费用承担及不同单位的可比耗能。可计划访谈使用者和管理人员，查制度或日志，配对相同期间的耗能记录。课件把费用责任列为候选解释，未提供实证结果。

## 适用边界

个案可提出解释、修正理论或澄清机制。统计推广需要相应抽样与数据。极端值要有比较依据，异例要有可检验的理论预期。研究者熟悉案例有助于进入场域，也需记录立场和可能的盲点。若只有传闻或零散摘录，把判断写成待核假设。课件给出的多案数量属于篇幅与资源建议，按问题和比较能力确定。

## 方法依据与课件出处

个案是组成部分彼此关联、可界定范围的个人、组织、网络或事件。案例立足于特定时空，可以深入还原过程、诊断问题或检验某个解释的适用条件。选什么案例，取决于要观察的机制、异常或差异。调查可以同时用访谈、观察和档案，分别保存各类资料原有口径，由研究问题决定如何相互核对。写作时交代时间线、证据和可能的替代解释。

> “个案研究设计”如同漏斗状，启于广泛探索，再挪向具体直接的资料搜集与分析
