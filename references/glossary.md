# 社会调研术语对照

| 术语 | 在实操中用来区分什么 | 课件来源 |
|---|---|---|
| 4P | 以人群、问题、方案、现象四类切入点找研究焦点，同一题目可跨类 | Ch.2 第 7–8 页 |
| 研究问题 | 需要用资料回答的疑问，范围和条件要清楚。假设是有依据且可检验的预期 | Ch.2 第 5、10–12 页 |
| 文献综述 | 整理既有研究的立场、证据和争论，用来说明本研究的位置 | Ch.1 第 19–23 页，Ch.2 第 14–37 页 |
| 操作化 | 把抽象概念说明到可用经验资料判断或测量，常逐层列出维度、指标与记录规则 | Ch.3 第 19–20 页 |
| 探索、描述、解释 | 初步弄清未知现象、系统刻画已界定对象、进一步考察关系和解释 | Ch.3 第 4–15 页 |
| 序列解释性混合设计 | 先得到定量发现，再用有针对性的质性资料解释特定结果，并在最后整合 | Ch.3 第 44–48 页 |
| 初级资料与次级资料 | 为本项目直接收集的资料，以及项目开始前已有的资料 | Ch.10 第 13–16 页 |
| 总体、抽样框与抽样单位 | 希望描述的全体、实际可用的名册或选取范围，以及在某一级被选取的对象 | Ch.4 第 11–17 页 |
| 分层与整群 | 分层抽样在各层分别取样，单阶段整群抽样调查所中群内全部单位，多阶段抽样在所中群内继续抽取 | Ch.4 第 28–40 页 |
| 信度与效度 | 测量结果的一致性，以及对所要测量概念解释的证据充分性 | Ch.7 第 22–35 页 |
| 前测 | 用小规模试施发现理解、题序、时长和记录问题，修订后再正式收集 | Ch.7 第 49–51 页，Ch.10 第 18 页 |
| 分析单位 | 最终希望对其作解释的对象，例如个人、班级、项目、帖子或案例。抽样和编码记录可以使用不同层级 | Ch.5 第 20–30 页，Ch.9 第 15–21 页 |
| 半结构访谈 | 保持一组共同主题，按受访者讲述顺序用开放问题追问具体经历 | Ch.8 第 24–35 页 |
| 开放、主轴与选择性编码 | 从片段发现概念、组织类别及关系、围绕核心范畴整合解释。使用完整扎根理论还需匹配其取样等条件 | Ch.8 第 39–48 页 |
| 内容分析 | 把传播或社会材料按明确范围和单位进行可重复的分类、比较或数量化 | Ch.9 第 2–21 页 |
| 数码叙事 | 以文字、影像、声音等讲述某一视角下的经验。在项目中可作为方法、生成的资料或传播形式 | SP 第 13–15、23–30、39–49 页 |
