# 决策规则速查 — 社会调研与社科论文写作方法

| 能力 | 一句话规则 |
|---|---|
| 选题与研究问题 | 用可接触的对象、场域、时间和证据把泛题目收束成可回答的主问题。 |
| 文献检索与综述 | 围绕问题评读和比较既有研究，交代对应证据、分歧与本项目的切入点。 |
| 研究设计与资料收集 | 由研究目的反推资料及分析。存在方法组合时明确前后阶段如何衔接。 |
| 抽样方案与推断边界 | 先对齐总体、抽样框和抽样单位，再判断选样方法与结论可外推到哪里。 |
| 个案研究设计与分析 | 先界定案例与选案理由，再在案例内和案例间用资料检验解释。 |
| 调研策划书与展示 | 把拟做的研究写成可审查的方案，交代问题、证据需求、执行步骤和预期成果。 |
| 问卷设计、前测与施测 | 先定义要测的变量和对象，为每个题项保留测量用途、作答规则及前测记录。 |
| 质性访谈、日志与编码 | 用开放中立的问题获取具体经历，以可定位原话、研究日志及编码备忘支撑解释。 |
| 内容分析与编码 | 界定分析材料与单位，统一分类和编码规则，再报告符合明确分母的结果。 |
| 实证论文、调研报告与质量评估 | 每项结论都回到研究问题、实际实施过程及可核的证据，明确适用范围。 |
| 数码叙事与社科成果传播 | 先明确叙事是研究资料还是传播成品，再对齐故事结构、证据与素材使用范围。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
